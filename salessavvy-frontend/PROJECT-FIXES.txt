SALESSAVVY FRONTEND - REVIEWED PATCH

Changes included:
1. Vite is configured to use localhost:5173 only (strictPort=true). It will stop with an error rather than silently switching to 5174 if another process occupies 5173.
2. ProductDetails.jsx has been restored to the original frontend version from fee.zip. This preserves the existing product/cart/wishlist/review behavior instead of the regressed edits in fe(1).zip.
3. MyReviews.jsx uses the existing Axios API client (including the existing JWT interceptor), includes the shared Navbar and Footer, handles loading/errors, and links back to each product.
4. The customer Navbar now includes My Reviews.
5. App.jsx keeps the /my-reviews customer-protected route.

INSTALL / RUN:
- Back up your current sales-savvy-frontend folder.
- Extract this ZIP into a NEW folder, or replace the existing frontend folder with its contents.
- Open a terminal in the extracted frontend folder.
- Run: npm install
- Run: npm run dev
- Open: http://localhost:5173/

PORT 5173:
If 5173 is already occupied, open CMD and run:
  netstat -ano | findstr :5173
Find the PID on the LISTENING line. Check it:
  tasklist /FI "PID eq YOUR_PID"
If it is an old Node/Vite process, stop it:
  taskkill /PID YOUR_PID /F
Then run npm run dev again.
Do not kill an unfamiliar process.
